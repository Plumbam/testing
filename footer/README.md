## Найденный дефект

### BUG-F01 — битая ссылка «Топперы с начинкой под ключ» (404)

| Поле | Значение |
|------|----------|
| Серьёзность | Major: ссылка ведёт на несуществующую страницу, переход на сайт топперов теряется |
| Приоритет | High |
| Где | Футер → колонка «Фасовка» → «Топперы с начинкой под ключ» (то же в мегаменю) |
| Шаги | 1. Открыть https://cpcimpex.com/ <br>2. Прокрутить до футера <br>3. Нажать «Топперы с начинкой под ключ» |
| Ожидаемый результат | Открывается https://toppers.cpcimpex.com/ |
| Фактический результат | Открывается `https://cpcimpex.com/https://toppers.cpcimpex.com/` → **404** |
| Вероятная причина | В CMS абсолютный адрес сохранён как относительный, и к нему приклеивается адрес сайта |
| Автотест | test 9, помечен `test.fail()`. Когда баг исправят, Playwright сообщит об этом, и пометку нужно снять |

## Важно: сайт блокирует headless-браузер

В headless-режиме Chromium отправляет `User-Agent` и `sec-ch-ua` со словом `HeadlessChrome`. На такие запросы cpcimpex.com отвечает **HTTP 200 с пустым телом**, и падает любой тест. В режиме `--headed` проблемы нет, поэтому её легко не заметить.

В `playwright.config.ts` оба заголовка подменены на обычный Chrome. Тем, кто пишет тесты для других блоков сайта, нужно сделать то же самое (в Python/pytest через фикстуру `browser_context_args`: `user_agent` и `extra_http_headers`).

## Запуск

```bash
cd footer
npm install
npx playwright install chromium

npm test              # все 10 тестов
npm run test:ui       # UI-режим: тесты по шагам со снимками страницы
npx playwright test --headed          # с видимым браузером
npx playwright test -g "Контакты" --debug   # один тест по шагам
npm run report        # HTML-отчёт после прогона
```
